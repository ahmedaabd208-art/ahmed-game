# ⚽ تحدي الأساطير | Football Legends Memory Battle

لعبة موبايل تفاعلية مخصصة لنجوم كرة القدم العالمية مستوحاة من فكرة البطاقات الذكية، حيث تظهر بطاقات اللاعبين لثوانٍ معدودة في البداية لتنشيط الذاكرة ثم تُقلب تلقائياً، ويبدأ التحدي السريع لتخمين واكتشاف البطاقات المتشابهة!

---

## 🌟 مميزات اللعبة الرئيسية

1. **مرحلة الحفظ السريع (Flash Memorization Phase)**:
   - في بداية كل جولة، تظهر جميع بطاقات اللاعبين مكشوفة لمدة 3 إلى 4 ثوانٍ مع عداد تنازلي ومؤثرات صوتية.
   - تنقلب جميع البطاقات تلقائياً بحركة 3D انسيابية على ظهرها ذو التدرج الأنيق (المطابق تماماً لتصميم بطاقات الصورة المرفقة).
   - يبدأ اللاعب بالتخمين السريع واكتشاف الأزواج المتطابقة.

2. **دعم اللعب الزوجي مع الأصدقاء (1v1 Multiplayer)**:
   - **عبر الآيدي الخاص (Player ID)**: يحصل كل لاعب على آيدي فريد (مثل `STAR-7824`) يمكن نسخه ومشاركته بنقرة واحدة.
   - **أكواد الغرف الخاصة (Room Codes)**: إنشاء غرفة برمز مكون من 5 أرقام والانضمام الفوري.
   - **رمز الاستجابة السريعة (QR Code)**: يمكن لصديقك مسح رمز الـ QR مباشرة من كاميرا هاتفه للدخول للغرفة في ثانية واحدة!
   - **تزامن فوري بالوقت الحقيقي (Real-Time WebSockets)**: تناوب الأدوار، احتساب النقاط (+100 نقطة لكل تطابق)، وعرض دور كل لاعب بلون مميز.
   - **شريط تفاعلات سريعة**: إرسال إيموجيات حماسية مباشرة أثناء المباراة (⚽, 🔥, 🏆, 👏, 😱, 😂).

3. **أنماط لعب متعددة تناسب كل الأوقات**:
   - 🌐 **لعب أونلاين مع الأصدقاء**: عن بُعد عبر الإنترنت أو عبر شبكة الواي فاي المنزلية.
   - 📱 **لعب زوجي على نفس الهاتف (Pass & Play)**: تناوب الأدوار مع صديقك بجوارك على نفس الشاشة وبدون الحاجة لإنترنت!
   - ⏱️ **التحدي الفردي والسرعة (Solo Speedrun)**: تحدي الوقت والمحاولات للحصول على 3 نجوم ذهبية.
   - 🤖 **ضد الروبوت الذكي (Vs AI)**: تحدي الذكاء الاصطناعي بنظام ذاكرة محاكي للبشر.

4. **تصميم عصري واحترافي للهواتف (Mobile-First UI/UX)**:
   - بطاقات لاعبي كرة القدم بتصميم بطاقات FIFA FUT الذهبية (ميسي، رونالدو، مبابي، هالاند، فينيسيوس، صلاح، دي بروين، بيلينغهام، نيمار، مودريتش، بونو، ليفاندوفسكي).
   - واجهة عربية بالكامل بخطوط عصرية (Cairo و Tajawal).
   - مؤثرات صوتية احترافية عبر Web Audio API بدون أي تأخير، مع اهتزازات حسية (Haptic Vibration).
   - احتفالات الفوز بمؤثرات الشظايا الذهبية (Confetti).
   - دعم التثبيت كتطبيق موبايل كامل الشاشة (PWA: إضافة إلى الشاشة الرئيسية).

## 🚀 طريقة التشغيل واللعب

### 1. تشغيل السيرفر محلياً:
```bash
# تثبيت الحزم (إن لم تكن مثبتة)
npm install

# بناء ملفات الواجهة
npm run build

# تشغيل السيرفر
npm start
```

### 2. الفتح على الهاتف واللعب مع الأصدقاء:
عند تشغيل السيرفر يظهر لك عنوانان:
- للكمبيوتر: `http://localhost:3000`
- **للهاتف وأي جهاز على نفس شبكة الواي فاي**: 
  `http://172.20.10.2:3000` (أو عنوان الـ IP المحلي لجهازك).

افتح الرابط في متصفح Safari أو Chrome على الهاتف، ويمكنك اختيار "إضافة إلى الشاشة الرئيسية" (Add to Home Screen) ليعمل كتطبيق جوال أصيل بدون شريط المتصفح!
